# 🛡️ Risk Alert Classifier

🎥 **Project Video:** [Watch Here](VIDEO_LINK_HERE)

A machine learning project that predicts customer risk status (Low Risk / High Risk) using classification models, preprocessing pipelines, sampling techniques, and hyperparameter tuning. A Streamlit app provides interactive predictions.

## Project Structure
```text
.
├── data/        # Dataset CSV
├── model/       # Saved model (model.joblib)
├── notebook/    # Training notebook
├── outputs/     # Input schema and evaluation outputs
└── app.py       # Streamlit application
```

## Run the App
```bash
pip install -r requirements.txt
streamlit run app.py
```

Ensure `model/model.joblib` and `outputs/input_schema.json` exist before launching the app.
